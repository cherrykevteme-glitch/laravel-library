---

## 🚀 Лабораторная работа №12: REST API для чтения данных

В рамках лабораторной работы №12 реализован версионированный REST API (версия `v1`) для получения данных каталога в формате JSON. API поддерживает поиск, фильтрацию, сортировку, пагинацию, вывод вложенных данных через API Resources, а также ограничение частоты запросов (throttling).

---

## 📌 Основные эндпоинты API

Все запросы к API выполняются по базовому адресу: `/api/v1/`[cite: 1]  
По умолчанию действует ограничение в **60 запросов в минуту** (`throttle:60,1`)[cite: 1].

| Метод | HTTP-адрес | Описание | Параметры запроса (Query) | Код ответа |
| :--- | :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/ping` | Проверка доступности API | — | `200 OK` |
| `GET` | `/api/v1/books` | Список книг с фильтрацией и пагинацией | `q`, `genre`, `sort`, `per_page` | `200 OK`, `422 Unprocessable` |
| `GET` | `/api/v1/books/{id}` | Детальная информация о книге | — | `200 OK`, `404 Not Found` |
| `GET` | `/api/v1/books/random` | Случайная книга из каталога | — | `200 OK`, `404 Not Found` |
| `GET` | `/api/v1/stats` | Общая статистика каталога (из кэша) | — | `200 OK` |
| `GET` | `/api/v1/genres` | Список жанров с количеством книг | — | `200 OK` |
| `GET` | `/api/v1/genres/{id}/books` | Список книг конкретного жанра | `page` | `200 OK`, `404 Not Found` |

---

## 🛠 Подробное описание параметров для `/api/v1/books`

- **`q`** *(string, max: 100)* — поисковый запрос (поиск по названию или автору)[cite: 1].
- **`genre`** *(integer)* — ID жанра/категории для фильтрации[cite: 1].
- **`sort`** *(string)* — сортировка результатов. Допустимые значения: `title`, `year`, `-year` (по убыванию года)[cite: 1].
- **`per_page`** *(integer, 1–50)* — количество элементов на страницу (по умолчанию: `10`)[cite: 1].
